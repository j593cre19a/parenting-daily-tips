# 怀孕宝宝偏小吃什么好

> 更新时间：2026-09-11 (UTC+8)

十月怀胎，女性朋友在怀孕期间都会做各项检查，来提前预知肚子里小宝宝的状况。产检时，如果发现小宝宝有问题，准妈妈们可以及时做好预防措施，保护好小宝宝。很多女性朋友在孕期会发现自己的宝宝偏小。那么，怀孕时，宝宝偏小吃什么好呢?

**怀孕宝宝偏小吃什么好**

胎儿偏小，孕妈可以吃富含蛋白质的食物、含优质脂肪的食物、富含叶酸的蔬菜水果、富含钙质与铁的食物等。以上食物都有利于胎儿的生长发育。大家需要注意的是，在补充营养期间，切忌大鱼大肉，要注重饮食的营养均衡，少吃多餐，劳逸结合。此外，大家还可以适当补充营养品，如孕妇奶粉、复合维生素。

**孕吐怎么办**

孕妈在孕吐期间会有轻度挑食、食欲不振、恶心、呕吐、头晕及倦怠等症状，虽然这些症状都是怀孕的正常反应，但为了孕妈自身以及宝宝的健康着想，适当缓解孕吐是有必要的。那么孕吐怎么缓解?

1、放松身心，用从容的心态度过这一阶段，解除紧张、焦虑的不良情绪。注意休息，保证充足的睡眠。

2、选择清淡、易消化的食物，少食多餐并且经常变换花样促进食欲。

3、可口服维生素B1和B6，对孕吐严重者有一定的帮助。

4、孕吐可以吃姜来缓解。将鲜姜片含于口中，或者在饮水或喝牛奶时，冲入姜汁，这些都可以缓解恶心的症状。

5、适当运动可以缓解孕吐。适当参加一些轻缓的活动，如室外散步、做孕妇保健操等，都可改善心情，缓解孕吐不适。

大家在孕期会遇到各种各样情况，最重要的是时常保持愉悦的心情。这样子有助于孕妈自身与宝宝的健康发育。恶心、呕吐是孕期的正常现象，在孕后期会有所缓解。小编在此建议大家要按时产检，注意自己身体的各项指标的变化。
