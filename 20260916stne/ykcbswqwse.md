# 中国中医科学院领导赴自治区妇幼保健院慰问援疆专家

> 更新时间：2026-09-16 (UTC+8)

6月26日，**中国中医科学院党委书记查德忠****一行6人**赴疆，在新疆维吾尔自治区卫生健康委有关领导的陪同下，看望慰问了**自治区妇幼保健院****援疆专家史宇思**，并就援疆工作与医院相关领导进行了深入的沟通与交流。

中国中医科学院党委书记查德忠一行慰问自治区妇幼保健院援疆专家史宇思

在认真听取援疆干部人才基本情况介绍后，**查德忠**与援疆干部亲切交谈，了解他们在自治区妇幼保健院的工作及生活情况。他表示，援疆专家舍小家为大家，以饱满的工作热情奉献边疆，与医院的同行们同甘共苦、并肩奋斗，不仅为医院之间的交流合作搭建了桥梁，更为当地人民的健康做出了贡献，用实际行动展示了医院的良好形象。

查德忠一行参观自治区妇幼保健院院区

随后，**查德忠一行**参观了自治区妇幼保健院院区，强调要继续加强双方医院的沟通、交流，充分发挥自身优势，持续做好医院的帮扶工作，推进更深层次的合作。双方医院要在人才培养上下功夫，毫不保留地进行传帮带，留下带不走的工作队。

**自治区妇幼保健院党委书记、副院长牛伟亚表示，**一年援疆行，一生援疆情。援疆专家严谨、亲切、细致的工作方式，展现了使命担当，树立了良好表率，获得医院的一致认可和高度好评。

**牛伟亚表示，**多年来，中国中医科学院精准对接援疆需求、倾情投入援疆人才，结合医院发展实际进行了形式多样的帮扶，并取得了实实在在的成效。希望今后援疆之花不断结出硕果，为增进各族人民健康福祉、健康新疆建设作出新的更大的贡献。
